# v1.0.0 — Transactions, API Freeze & LTS

## Theme

Add transaction support for SQL and MongoDB drivers, stabilize the OmniQL API for long-term support, standardize error codes, expand the compliance suite to 70+ tests, and produce comprehensive documentation. This is the first production-grade release.

## Rationale

- **Transactions**: Production applications need atomicity — transferring funds, creating orders with line items, etc. `TransactionalDriver` and `TxDriver` interfaces enable multi-step operations.
- **API Freeze**: Downstream consumers (language bindings, FFI users, OmniModel) need stability guarantees. After v1.0.0, `core.Driver`, `core.TransactionalDriver`, `core.OQLQuery`, and `core.OmniJSON` become backwards-compatible within the v1.x series.
- **Error Standardization**: Current error codes are ad-hoc. A formal error code registry enables programmatic error handling across all bindings.
- **Compliance Expansion**: 50 tests isn't enough for an LTS release. 70+ tests covering edge cases, empty sets, type coercion, and concurrent access ensure cross-driver parity.

## Deliverable 2: Error Code Standardization

### Error Code Registry

Define all error codes as constants in `pkg/core/errors.go`:

```go
package core

// Error codes returned in OmniError.Code.
const (
    // Engine-level errors
    ErrCodeSchemaError    = "SCHEMA_ERROR"    // Query failed schema validation
    ErrCodeDriverError    = "DRIVER_ERROR"    // No driver registered/routed for target
    ErrCodeNoDrivers      = "NO_DRIVERS"      // No drivers registered at all

    // Execution errors
    ErrCodeExecutionError = "EXECUTION_ERROR" // Driver returned error during execution
    ErrCodeParseError     = "PARSE_ERROR"     // JSON input couldn't be parsed
    ErrCodeMarshalError   = "MARSHAL_ERROR"   // Result couldn't be serialized to JSON

    // Driver initialization
    ErrCodeDriverInitError = "DRIVER_INIT_ERROR" // Driver constructor failed

    // Handle errors (FFI)
    ErrCodeInvalidHandle  = "INVALID_HANDLE"  // FFI handle doesn't map to engine

    // Transaction errors
    ErrCodeTxError        = "TRANSACTION_ERROR" // Transaction begin/commit/rollback failed
    ErrCodeTxNotSupported = "TX_NOT_SUPPORTED"  // Driver doesn't implement TransactionalDriver

    // Action errors
    ErrCodeUnsupportedAction = "UNSUPPORTED_ACTION" // Driver doesn't support the requested action

    // Validation errors
    ErrCodeInvalidFilter  = "INVALID_FILTER"  // Malformed filter expression
    ErrCodeInvalidTarget  = "INVALID_TARGET"  // Empty or invalid target name
    ErrCodeInvalidAction  = "INVALID_ACTION"  // Unknown action type
)
```

### Update All Error Sites

Replace string literals with constants throughout:
- `pkg/core/engine.go` — `errorResponse(err, ErrCodeSchemaError)` etc.
- `pkg/ffi/ffi.go` — all JSON error returns

## Deliverable 3: Transaction Support

### New Interfaces (`pkg/core/driver.go`)

```go
// TransactionalDriver extends Driver with transaction support.
type TransactionalDriver interface {
    Driver
    Begin(ctx context.Context) (TxDriver, error)
}

// TxDriver is a driver scoped to a single transaction.
type TxDriver interface {
    Execute(ctx context.Context, query OQLQuery) ([]map[string]interface{}, int64, error)
    BatchInsert(ctx context.Context, target string, docs []map[string]interface{}) ([]map[string]interface{}, error)
    Commit() error
    Rollback() error
}
```

### Engine Transaction API

```go
// ExecuteTx runs a function within a transaction. Commits on nil, rolls back on error.
func (e *Engine) ExecuteTx(ctx context.Context, target string, fn func(tx TxDriver) error) (*OmniJSON, error)
```

### SQL Implementation Pattern

All SQL drivers share the same pattern — wrap `*sql.Tx`:

```go
type txDriver struct {
    tx     *sql.Tx
    driver *Driver
}

func (d *Driver) Begin(ctx context.Context) (core.TxDriver, error) {
    tx, err := d.db.BeginTx(ctx, nil)
    if err != nil { return nil, err }
    return &txDriver{tx: tx, driver: d}, nil
}
func (t *txDriver) Commit() error   { return t.tx.Commit() }
func (t *txDriver) Rollback() error { return t.tx.Rollback() }
```

Refactor each SQL driver's execute methods to accept a `queryExecutor` interface (`*sql.DB` and `*sql.Tx` both satisfy) to avoid duplicating query-building logic.

### MongoDB Implementation

Uses `mongo.Session` with `StartTransaction`/`CommitTransaction`.

### FFI Transaction Exports

## Deliverable 4: Compliance Suite Expansion to 70+ Tests

### New Test Categories

Add the following test categories to `pkg/compliance/suite_test.go`:

**Edge Cases (10+ tests):**
- Empty filter returns all records
- Filter with no matches returns empty data array
- INSERT with empty document
- UPDATE with no matching filter (zero affected)
- DELETE with no matching filter (zero affected)
- COUNT with empty table
- FIND with limit=0 (should return empty or all depending on driver)
- Very long string values (1000+ chars)
- Unicode characters in filter values and document fields
- Numeric precision (float64 edge cases)

**Type Coercion (5+ tests):**
- Integer stored, queried as float
- String "123" vs integer 123 in filter
- Boolean values across drivers
- Null/nil handling in filters and documents
- Date-like strings

**Concurrent Access (5+ tests):**
- Parallel FIND operations
- Parallel INSERT operations
- Mixed read/write operations
- COUNT during concurrent INSERTs

**Sort & Pagination (5+ tests):**
- Sort ascending + descending on same field
- Multi-field sort
- Skip without limit
- Skip exceeding total records
- Limit exceeding total records

### OQLQuery.Validate()

```go
func (q OQLQuery) Validate() error {
    if q.Target == "" {
        return fmt.Errorf("target is required")
    }
    switch q.Action {
    case ActionFind, ActionInsert, ActionBatchInsert, ActionUpdate, ActionDelete, ActionCount:
        // valid
    case "":
        return fmt.Errorf("action is required")
    default:
        return fmt.Errorf("unknown action: %q", q.Action)
    }
    if q.Action == ActionInsert && len(q.Document) == 0 {
        return fmt.Errorf("document is required for INSERT")
    }
    if q.Action == ActionBatchInsert && len(q.Documents) == 0 {
        return fmt.Errorf("documents is required for BATCH_INSERT")
    }
    if q.Action == ActionUpdate && len(q.Document) == 0 {
        return fmt.Errorf("document is required for UPDATE")
    }
    return nil
}
```
