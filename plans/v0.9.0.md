# v0.9.0 — OmniModel: Active Record ORM for All Bindings

## Theme

Introduce the OmniModel pattern — an Active Record-style ORM layer — across all four language bindings (Python, Java, C#, TypeScript). This gives developers a Prisma/Django/Eloquent-like experience while preserving OmniQL's database-agnostic routing underneath.

## Rationale

- **Developer ergonomics** are the primary barrier to OmniQL adoption. Raw dict/map-based queries work but feel low-level compared to modern ORMs.
- The OmniModel pattern (discussed in `discussion-4.md`) provides: type-safe fields, automatic OQL JSON construction, `.save()`/`.delete()` lifecycle methods, and class-level query methods.
- Implementing across **all four bindings simultaneously** ensures first-class support regardless of language — Python, Java, C#, and TypeScript developers all get the same capabilities.
- This is a **binding-layer** change only — no Go code is modified. Each language implements OmniModel idiomatically on top of the existing FFI bridge.

---

## Architecture (All Languages)

```
Application Code
    │
    ├── OmniModel (Active Record layer — NEW)
    │       │
    │       └── OmniEngine (FFI bridge — existing)
    │               │
    │               └── libomniql.so (Go shared library — existing)
    │
    └── Direct engine.execute() (still available)
```

### Core Concepts (Language-Agnostic)

Every OmniModel implementation must provide:

1. **Model Definition** — Declare a model class with typed fields mapped to a `target` (table/collection)
2. **Field Types** — `StringField`, `IntField`, `FloatField`, `BoolField` with `required` and `default` options
3. **Dirty Tracking** — Track which fields changed since last load/save
4. **Instance Methods** — `.save()` (insert or update), `.delete()`, `.refresh()`, `.toDict()`/`.to_dict()`
5. **Class-Level Queries** — `.objects.findMany()`, `.objects.findFirst()`, `.objects.count()`, `.objects.deleteMany()`, `.objects.updateMany()`
6. **Schema Auto-Registration** — On `configure(engine)`, register the model's field schema with the engine
7. **Database-Agnostic** — The same model class works with any driver (SQLite, Postgres, Redis, etc.) — routing is handled by the engine

## Deliverable 1: Python OmniModel

### Implementation (`bindings/python/omniql/model.py`)

Python uses **metaclasses** and **descriptors** — the most natural pattern for Python ORMs (Django, SQLAlchemy declarative, Tortoise).

```python
from __future__ import annotations
from typing import Any, ClassVar
from omniql import OmniEngine


class Field:
    """Descriptor for OmniModel fields."""

    def __init__(self, field_type: str, required: bool = False, default: Any = None):
        self.field_type = field_type
        self.required = required
        self.default = default
        self.name: str = ""

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj._data.get(self.name, self.default)

    def __set__(self, obj, value):
        obj._data[self.name] = value
        obj._dirty.add(self.name)


class StringField(Field):
    def __init__(self, **kwargs): super().__init__("string", **kwargs)

class IntField(Field):
    def __init__(self, **kwargs): super().__init__("int", **kwargs)

class FloatField(Field):
    def __init__(self, **kwargs): super().__init__("float", **kwargs)

class BoolField(Field):
    def __init__(self, **kwargs): super().__init__("bool", **kwargs)


class ModelMeta(type):
    """Metaclass that collects Field descriptors and builds schema."""
    def __new__(mcs, name, bases, namespace):
        fields = {}
        for key, val in namespace.items():
            if isinstance(val, Field):
                val.name = key
                fields[key] = val
        cls = super().__new__(mcs, name, bases, namespace)
        cls._fields = fields
        return cls


class QuerySet:
    """Class-level query interface for OmniModel."""

    def __init__(self, model_cls: type[OmniModel]):
        self._model_cls = model_cls

    async def find_many(self, filter: dict | None = None, **options) -> list[OmniModel]:
        engine = self._model_cls._engine
        target = self._model_cls.__target__
        docs = await engine.find_many(target, filter or {}, options)
        return [self._model_cls._from_doc(doc) for doc in docs]

    async def find_first(self, filter: dict | None = None) -> OmniModel | None:
        engine = self._model_cls._engine
        target = self._model_cls.__target__
        doc = await engine.find_first(target, filter or {})
        return self._model_cls._from_doc(doc) if doc else None

    async def count(self, filter: dict | None = None) -> int:
        return await self._model_cls._engine.count(self._model_cls.__target__, filter or {})

    async def delete_many(self, filter: dict) -> dict:
        return await self._model_cls._engine.delete_many(self._model_cls.__target__, filter)

    async def update_many(self, filter: dict, update: dict) -> dict:
        return await self._model_cls._engine.update_many(self._model_cls.__target__, filter, update)

    # Synchronous variants
    def find_many_sync(self, filter: dict | None = None, **options) -> list:
        engine = self._model_cls._engine
        target = self._model_cls.__target__
        docs = engine.find_many_sync(target, filter or {}, options)
        return [self._model_cls._from_doc(doc) for doc in docs]

    def find_first_sync(self, filter: dict | None = None):
        engine = self._model_cls._engine
        target = self._model_cls.__target__
        doc = engine.find_first_sync(target, filter or {})
        return self._model_cls._from_doc(doc) if doc else None

    def count_sync(self, filter: dict | None = None) -> int:
        return self._model_cls._engine.count_sync(self._model_cls.__target__, filter or {})


class OmniModel(metaclass=ModelMeta):
    """Active Record base class for OmniQL."""

    __target__: ClassVar[str] = ""
    _engine: ClassVar[OmniEngine | None] = None
    _fields: ClassVar[dict[str, Field]] = {}
    objects: ClassVar[QuerySet]

    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        cls.objects = QuerySet(cls)

    def __init__(self, **kwargs):
        self._data: dict[str, Any] = {}
        self._dirty: set[str] = set()
        self._persisted: bool = False
        for name, field in self._fields.items():
            if name in kwargs:
                self._data[name] = kwargs[name]
            elif field.default is not None:
                self._data[name] = field.default

    @classmethod
    def configure(cls, engine: OmniEngine):
        """Bind model to an engine and auto-register schema."""
        cls._engine = engine
        schema = {"name": cls.__target__, "fields": {}}
        for name, field in cls._fields.items():
            schema["fields"][name] = {"type": field.field_type, "required": field.required}
        engine.register_schema(schema)

    @classmethod
    def _from_doc(cls, doc: dict) -> OmniModel:
        instance = cls.__new__(cls)
        instance._data = dict(doc)
        instance._dirty = set()
        instance._persisted = True
        return instance

    def to_dict(self) -> dict:
        return dict(self._data)

    async def save(self) -> None:
        if self._engine is None:
            raise RuntimeError(f"{type(self).__name__} not configured")
        for name, field in self._fields.items():
            if field.required and name not in self._data:
                raise ValueError(f"Required field '{name}' is missing")
        if self._persisted:
            if not self._dirty:
                return
            update_doc = {k: self._data[k] for k in self._dirty if k in self._data}
            id_val = self._data.get("id") or self._data.get("_id")
            if id_val is None:
                raise ValueError("Cannot update without id or _id")
            id_key = "id" if "id" in self._data else "_id"
            await self._engine.update_many(self.__target__, {id_key: id_val}, update_doc)
        else:
            result = await self._engine.insert_one(self.__target__, self._data)
            if result and isinstance(result, dict):
                self._data.update(result)
            self._persisted = True
        self._dirty.clear()

    async def delete(self) -> None:
        if self._engine is None:
            raise RuntimeError(f"{type(self).__name__} not configured")
        if not self._persisted:
            raise ValueError("Cannot delete a record that hasn't been saved")
        id_val = self._data.get("id") or self._data.get("_id")
        if id_val is None:
            raise ValueError("Cannot delete without id or _id")
        id_key = "id" if "id" in self._data else "_id"
        await self._engine.delete_many(self.__target__, {id_key: id_val})
        self._persisted = False

    async def refresh(self) -> None:
        if self._engine is None:
            raise RuntimeError(f"{type(self).__name__} not configured")
        id_val = self._data.get("id") or self._data.get("_id")
        if id_val is None:
            raise ValueError("Cannot refresh without id or _id")
        id_key = "id" if "id" in self._data else "_id"
        doc = await self._engine.find_first(self.__target__, {id_key: id_val})
        if doc is not None:
            self._data = dict(doc)
            self._dirty.clear()

    def __repr__(self) -> str:
        cls_name = type(self).__name__
        fields_str = ", ".join(f"{k}={v!r}" for k, v in self._data.items())
        return f"{cls_name}({fields_str})"
```

## Deliverable 2: Java OmniModel

### Implementation (`bindings/java/src/main/java/io/omniql/OmniModel.java`)

Java uses **annotations** and **generics** — idiomatic for Spring/JPA developers. The pattern mirrors Spring Data repositories.

```java
package io.omniql;

import java.lang.annotation.*;
import java.lang.reflect.Field;
import java.util.*;

// --- Annotations ---

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
public @interface Target {
    String value();  // collection/table name
}

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
public @interface OmniField {
    String type() default "any";
    boolean required() default false;
}

// --- Base Model ---

public abstract class OmniModel {

    private final Map<String, Object> data = new LinkedHashMap<>();
    private final Set<String> dirty = new HashSet<>();
    private boolean persisted = false;

    // Each subclass gets its own static engine reference
    private static final Map<Class<?>, OmniEngine> engines = new HashMap<>();

    public static <T extends OmniModel> void configure(Class<T> modelClass, OmniEngine engine) {
        engines.put(modelClass, engine);
        // Auto-register schema
        Target target = modelClass.getAnnotation(Target.class);
        if (target != null) {
            Map<String, CollectionSchema.FieldSchema> fields = new LinkedHashMap<>();
            for (Field f : modelClass.getDeclaredFields()) {
                OmniField ann = f.getAnnotation(OmniField.class);
                if (ann != null) {
                    fields.put(f.getName(), new CollectionSchema.FieldSchema(ann.type(), ann.required()));
                }
            }
            engine.registerSchema(new CollectionSchema(target.value(), fields));
        }
    }

    protected OmniEngine engine() {
        OmniEngine e = engines.get(this.getClass());
        if (e == null) throw new IllegalStateException(getClass().getSimpleName() + " not configured");
        return e;
    }

    protected String targetName() {
        Target t = getClass().getAnnotation(Target.class);
        if (t == null) throw new IllegalStateException("Missing @Target annotation");
        return t.value();
    }

    // --- Data access ---

    public Object get(String field) { return data.get(field); }

    public void set(String field, Object value) {
        data.put(field, value);
        dirty.add(field);
    }

    public Map<String, Object> toMap() { return Collections.unmodifiableMap(data); }

    // --- Lifecycle ---

    public void save() {
        validate();
        if (persisted) {
            if (dirty.isEmpty()) return;
            Map<String, Object> updateDoc = new HashMap<>();
            for (String k : dirty) {
                if (data.containsKey(k)) updateDoc.put(k, data.get(k));
            }
            Object id = data.getOrDefault("id", data.get("_id"));
            if (id == null) throw new IllegalStateException("Cannot update without id or _id");
            String idKey = data.containsKey("id") ? "id" : "_id";
            engine().updateMany(targetName(), Map.of(idKey, id), updateDoc);
        } else {
            OmniEngine.OmniResult result = engine().insertOne(targetName(), data);
            if (result.data != null && !result.data.isEmpty()) {
                data.putAll(result.data.get(0));
            }
            persisted = true;
        }
        dirty.clear();
    }

    public void delete() {
        if (!persisted) throw new IllegalStateException("Cannot delete unsaved record");
        Object id = data.getOrDefault("id", data.get("_id"));
        if (id == null) throw new IllegalStateException("Cannot delete without id or _id");
        String idKey = data.containsKey("id") ? "id" : "_id";
        engine().deleteMany(targetName(), Map.of(idKey, id));
        persisted = false;
    }

    public void refresh() {
        Object id = data.getOrDefault("id", data.get("_id"));
        if (id == null) throw new IllegalStateException("Cannot refresh without id or _id");
        String idKey = data.containsKey("id") ? "id" : "_id";
        Map<String, Object> doc = engine().findFirst(targetName(), Map.of(idKey, id));
        if (doc != null) {
            data.clear();
            data.putAll(doc);
            dirty.clear();
        }
    }

    private void validate() {
        for (Field f : getClass().getDeclaredFields()) {
            OmniField ann = f.getAnnotation(OmniField.class);
            if (ann != null && ann.required() && !data.containsKey(f.getName())) {
                throw new IllegalStateException("Required field '" + f.getName() + "' is missing");
            }
        }
    }

    // --- Factory ---

    @SuppressWarnings("unchecked")
    static <T extends OmniModel> T fromDoc(Class<T> cls, Map<String, Object> doc) {
        try {
            T instance = cls.getDeclaredConstructor().newInstance();
            instance.data.putAll(doc);
            instance.persisted = true;
            return instance;
        } catch (Exception e) {
            throw new RuntimeException("Failed to create " + cls.getSimpleName(), e);
        }
    }
}
```

public class OmniQuery<T extends OmniModel> {

    private final Class<T> modelClass;
    private final OmniEngine engine;
    private final String target;

    public OmniQuery(Class<T> modelClass) {
        this.modelClass = modelClass;
        this.engine = /* resolve from static map */;
        Target t = modelClass.getAnnotation(Target.class);
        this.target = t.value();
    }

    public List<T> findMany(Map<String, Object> filter) {
        List<Map<String, Object>> docs = engine.findMany(target, filter);
        List<T> results = new ArrayList<>();
        for (Map<String, Object> doc : docs) {
            results.add(OmniModel.fromDoc(modelClass, doc));
        }
        return results;
    }

    public T findFirst(Map<String, Object> filter) {
        Map<String, Object> doc = engine.findFirst(target, filter);
        return doc != null ? OmniModel.fromDoc(modelClass, doc) : null;
    }

    public long count(Map<String, Object> filter) {
        return engine.count(target, filter);
    }

    public void deleteMany(Map<String, Object> filter) {
        engine.deleteMany(target, filter);
    }

    public void updateMany(Map<String, Object> filter, Map<String, Object> update) {
        engine.updateMany(target, filter, update);
    }
}

## Deliverable 3: C# OmniModel

### Implementation (`bindings/csharp/OmniQL/OmniModel.cs`)

C# uses **attributes** and **generics** — idiomatic for Entity Framework / ASP.NET developers. Fully async with `Task<>`.

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Reflection;
using System.Threading.Tasks;

namespace OmniQL
{
    // --- Attributes ---

    [AttributeUsage(AttributeTargets.Class)]
    public class TargetAttribute : Attribute
    {
        public string Name { get; }
        public TargetAttribute(string name) => Name = name;
    }

    [AttributeUsage(AttributeTargets.Property)]
    public class OmniFieldAttribute : Attribute
    {
        public string Type { get; set; } = "any";
        public bool Required { get; set; } = false;
    }

    // --- Base Model ---

    public abstract class OmniModel
    {
        private readonly Dictionary<string, object?> _data = new();
        private readonly HashSet<string> _dirty = new();
        private bool _persisted = false;

        private static readonly Dictionary<Type, OmniEngine> _engines = new();

        public static void Configure<T>(OmniEngine engine) where T : OmniModel
        {
            _engines[typeof(T)] = engine;
            // Auto-register schema
            var targetAttr = typeof(T).GetCustomAttribute<TargetAttribute>();
            if (targetAttr == null) return;
            var fields = new Dictionary<string, object>();
            foreach (var prop in typeof(T).GetProperties())
            {
                var fieldAttr = prop.GetCustomAttribute<OmniFieldAttribute>();
                if (fieldAttr == null) continue;
                fields[prop.Name] = new Dictionary<string, object>
                {
                    ["type"] = fieldAttr.Type,
                    ["required"] = fieldAttr.Required
                };
            }
            engine.RegisterSchema(new CollectionSchema { Name = targetAttr.Name, Fields = fields });
        }

        protected OmniEngine Engine
        {
            get
            {
                if (!_engines.TryGetValue(GetType(), out var e))
                    throw new InvalidOperationException($"{GetType().Name} not configured");
                return e;
            }
        }

        protected string TargetName
        {
            get
            {
                var attr = GetType().GetCustomAttribute<TargetAttribute>();
                if (attr == null) throw new InvalidOperationException("Missing [Target] attribute");
                return attr.Name;
            }
        }

        // --- Data Access ---

        public object? Get(string field) => _data.GetValueOrDefault(field);

        public void Set(string field, object? value)
        {
            _data[field] = value;
            _dirty.Add(field);
        }

        public Dictionary<string, object?> ToDict() => new(_data);

        // --- Lifecycle ---

        public async Task SaveAsync()
        {
            Validate();
            if (_persisted)
            {
                if (_dirty.Count == 0) return;
                var updateDoc = _dirty
                    .Where(k => _data.ContainsKey(k))
                    .ToDictionary(k => k, k => _data[k]);
                var id = _data.GetValueOrDefault("id") ?? _data.GetValueOrDefault("_id");
                if (id == null) throw new InvalidOperationException("Cannot update without id or _id");
                var idKey = _data.ContainsKey("id") ? "id" : "_id";
                await Engine.UpdateManyAsync(TargetName,
                    new Dictionary<string, object> { [idKey] = id },
                    updateDoc!);
            }
            else
            {
                var result = await Engine.InsertOneAsync(TargetName, _data!);
                if (result.Data?.Count > 0)
                {
                    foreach (var kv in result.Data[0])
                        _data[kv.Key] = kv.Value;
                }
                _persisted = true;
            }
            _dirty.Clear();
        }

        public async Task DeleteAsync()
        {
            if (!_persisted) throw new InvalidOperationException("Cannot delete unsaved record");
            var id = _data.GetValueOrDefault("id") ?? _data.GetValueOrDefault("_id");
            if (id == null) throw new InvalidOperationException("Cannot delete without id or _id");
            var idKey = _data.ContainsKey("id") ? "id" : "_id";
            await Engine.DeleteManyAsync(TargetName,
                new Dictionary<string, object> { [idKey] = id });
            _persisted = false;
        }

        public async Task RefreshAsync()
        {
            var id = _data.GetValueOrDefault("id") ?? _data.GetValueOrDefault("_id");
            if (id == null) throw new InvalidOperationException("Cannot refresh without id or _id");
            var idKey = _data.ContainsKey("id") ? "id" : "_id";
            var doc = await Engine.FindFirstAsync(TargetName,
                new Dictionary<string, object> { [idKey] = id });
            if (doc != null)
            {
                _data.Clear();
                foreach (var kv in doc) _data[kv.Key] = kv.Value;
                _dirty.Clear();
            }
        }

        private void Validate()
        {
            foreach (var prop in GetType().GetProperties())
            {
                var attr = prop.GetCustomAttribute<OmniFieldAttribute>();
                if (attr is { Required: true } && !_data.ContainsKey(prop.Name))
                    throw new InvalidOperationException($"Required field '{prop.Name}' is missing");
            }
        }

        internal static T FromDoc<T>(Dictionary<string, object?> doc) where T : OmniModel, new()
        {
            var instance = new T();
            foreach (var kv in doc) instance._data[kv.Key] = kv.Value;
            instance._persisted = true;
            return instance;
        }
    }

    // --- Query Set ---

    public class OmniQuery<T> where T : OmniModel, new()
    {
        private readonly OmniEngine _engine;
        private readonly string _target;

        public OmniQuery(OmniEngine engine)
        {
            _engine = engine;
            var attr = typeof(T).GetCustomAttribute<TargetAttribute>();
            _target = attr?.Name ?? throw new InvalidOperationException("Missing [Target]");
        }

        public async Task<List<T>> FindManyAsync(Dictionary<string, object>? filter = null)
        {
            var docs = await _engine.FindManyAsync(_target, filter ?? new());
            return docs.Select(OmniModel.FromDoc<T>).ToList();
        }

        public async Task<T?> FindFirstAsync(Dictionary<string, object>? filter = null)
        {
            var doc = await _engine.FindFirstAsync(_target, filter ?? new());
            return doc != null ? OmniModel.FromDoc<T>(doc) : null;
        }

        public async Task<long> CountAsync(Dictionary<string, object>? filter = null)
            => await _engine.CountAsync(_target, filter);

        public async Task DeleteManyAsync(Dictionary<string, object> filter)
            => await _engine.DeleteManyAsync(_target, filter);

        public async Task UpdateManyAsync(Dictionary<string, object> filter, Dictionary<string, object> update)
            => await _engine.UpdateManyAsync(_target, filter, update);
    }
}
```

## Deliverable 4: TypeScript OmniModel

### Implementation (`bindings/typescript/omniql-model.ts`)

TypeScript uses **decorators** (stage 3) and **generics** — idiomatic for Prisma/TypeORM developers. Fully async with Promise.

```typescript
import { OmniEngine, OmniResult, Filter } from './omniql';

// --- Decorator Metadata ---

interface FieldDef {
  type: string;
  required: boolean;
  defaultValue?: unknown;
}

const MODEL_TARGET = Symbol('omniql:target');
const MODEL_FIELDS = Symbol('omniql:fields');

// --- Decorators ---

export function Target(name: string) {
  return function (constructor: Function) {
    Reflect.defineMetadata(MODEL_TARGET, name, constructor);
  };
}

export function OmniField(opts: { type?: string; required?: boolean; default?: unknown } = {}) {
  return function (target: any, propertyKey: string) {
    const fields: Map<string, FieldDef> =
      Reflect.getMetadata(MODEL_FIELDS, target.constructor) ?? new Map();
    fields.set(propertyKey, {
      type: opts.type ?? 'any',
      required: opts.required ?? false,
      defaultValue: opts.default,
    });
    Reflect.defineMetadata(MODEL_FIELDS, fields, target.constructor);
  };
}

// --- Base Model ---

export abstract class OmniModel {
  private _data: Record<string, unknown> = {};
  private _dirty: Set<string> = new Set();
  private _persisted = false;

  private static engines = new Map<Function, OmniEngine>();

  static configure<T extends OmniModel>(
    this: new () => T,
    engine: OmniEngine
  ): void {
    OmniModel.engines.set(this, engine);
    // Auto-register schema
    const target = Reflect.getMetadata(MODEL_TARGET, this) as string;
    const fieldDefs = Reflect.getMetadata(MODEL_FIELDS, this) as Map<string, FieldDef> | undefined;
    if (target && fieldDefs) {
      const fields: Record<string, { type: string; required: boolean }> = {};
      for (const [name, def] of fieldDefs) {
        fields[name] = { type: def.type, required: def.required };
      }
      engine.registerSchema({ name: target, fields });
    }
  }

  protected get engine(): OmniEngine {
    const e = OmniModel.engines.get(this.constructor);
    if (!e) throw new Error(`${this.constructor.name} not configured`);
    return e;
  }

  protected get targetName(): string {
    const t = Reflect.getMetadata(MODEL_TARGET, this.constructor) as string;
    if (!t) throw new Error(`Missing @Target on ${this.constructor.name}`);
    return t;
  }

  // --- Data Access ---

  get(field: string): unknown { return this._data[field]; }

  set(field: string, value: unknown): void {
    this._data[field] = value;
    this._dirty.add(field);
  }

  toObject(): Record<string, unknown> { return { ...this._data }; }

  // --- Lifecycle ---

  async save(): Promise<void> {
    this.validate();
    if (this._persisted) {
      if (this._dirty.size === 0) return;
      const updateDoc: Record<string, unknown> = {};
      for (const k of this._dirty) {
        if (k in this._data) updateDoc[k] = this._data[k];
      }
      const id = this._data['id'] ?? this._data['_id'];
      if (id == null) throw new Error('Cannot update without id or _id');
      const idKey = 'id' in this._data ? 'id' : '_id';
      await this.engine.updateMany(this.targetName, { [idKey]: id }, updateDoc);
    } else {
      const result = await this.engine.insertOne(this.targetName, this._data);
      if (result.data?.[0]) {
        Object.assign(this._data, result.data[0]);
      }
      this._persisted = true;
    }
    this._dirty.clear();
  }

  async delete(): Promise<void> {
    if (!this._persisted) throw new Error('Cannot delete unsaved record');
    const id = this._data['id'] ?? this._data['_id'];
    if (id == null) throw new Error('Cannot delete without id or _id');
    const idKey = 'id' in this._data ? 'id' : '_id';
    await this.engine.deleteMany(this.targetName, { [idKey]: id });
    this._persisted = false;
  }

  async refresh(): Promise<void> {
    const id = this._data['id'] ?? this._data['_id'];
    if (id == null) throw new Error('Cannot refresh without id or _id');
    const idKey = 'id' in this._data ? 'id' : '_id';
    const doc = await this.engine.findFirst(this.targetName, { [idKey]: id });
    if (doc) {
      this._data = { ...doc };
      this._dirty.clear();
    }
  }

  private validate(): void {
    const fieldDefs = Reflect.getMetadata(MODEL_FIELDS, this.constructor) as Map<string, FieldDef> | undefined;
    if (!fieldDefs) return;
    for (const [name, def] of fieldDefs) {
      if (def.required && !(name in this._data)) {
        throw new Error(`Required field '${name}' is missing`);
      }
    }
  }

  static _fromDoc<T extends OmniModel>(this: new () => T, doc: Record<string, unknown>): T {
    const instance = new this();
    (instance as any)._data = { ...doc };
    (instance as any)._persisted = true;
    return instance;
  }
}

// --- Query Set ---

export class OmniQuery<T extends OmniModel> {
  private readonly modelClass: new () => T;
  private readonly engine: OmniEngine;
  private readonly target: string;

  constructor(modelClass: new () => T, engine: OmniEngine) {
    this.modelClass = modelClass;
    this.engine = engine;
    this.target = Reflect.getMetadata(MODEL_TARGET, modelClass) as string;
  }

  async findMany(filter?: Filter): Promise<T[]> {
    const docs = await this.engine.findMany<Record<string, unknown>>(this.target, filter);
    return docs.map(doc => (this.modelClass as any)._fromDoc(doc));
  }

  async findFirst(filter?: Filter): Promise<T | undefined> {
    const doc = await this.engine.findFirst<Record<string, unknown>>(this.target, filter);
    return doc ? (this.modelClass as any)._fromDoc(doc) : undefined;
  }

  async count(filter?: Filter): Promise<number> {
    return this.engine.count(this.target, filter);
  }

  async deleteMany(filter: Filter): Promise<OmniResult> {
    return this.engine.deleteMany(this.target, filter);
  }

  async updateMany(filter: Filter, update: Record<string, unknown>): Promise<OmniResult> {
    return this.engine.updateMany(this.target, filter, update);
  }
}
```

### Usage

```typescript
@Target('users')
class User extends OmniModel {
  @OmniField({ type: 'string', required: true }) name!: string;
  @OmniField({ type: 'string' }) email!: string;
  @OmniField({ type: 'int' }) age!: number;
}

// Configure
User.configure(engine);

// Create and save
const user = new User();
user.set('name', 'Alice');
user.set('email', 'alice@test.com');
user.set('age', 25);
await user.save();

// Query
const query = new OmniQuery(User, engine);
const adults = await query.findMany({ age: { $gt: 18 } });
const first = await query.findFirst({ name: 'Alice' });
const count = await query.count();

// Update
user.set('age', 26);
await user.save();  // Only sends {"age": 26}

// Delete
await user.delete();
```

### TypeScript Note on Decorators

TypeScript decorators require `reflect-metadata` polyfill and `"experimentalDecorators": true` in `tsconfig.json`. If the project prefers to avoid experimental decorators, an alternative static-registration pattern is provided:

```typescript
// Alternative: no decorators
class User extends OmniModel {
  static readonly __target = 'users';
  static readonly __fields = {
    name:  { type: 'string', required: true },
    email: { type: 'string' },
    age:   { type: 'int' },
  };
}
```
