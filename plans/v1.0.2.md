# v1.0.2 — Graph Database Support

## Theme

Add Neo4j as OmniQL's first graph database driver, translating OQL queries into Cypher. This extends OmniQL's paradigm coverage to five database paradigms: relational, document, key-value, time-series, and graph.

## Rationale

- **Graph databases** are essential for social networks, recommendation engines, fraud detection, and knowledge graphs — use cases that AI agents encounter frequently.
- **Neo4j** is the most widely adopted graph database, with a mature Go driver and well-documented Cypher query language.
- OQL's intent-based query model maps naturally to Cypher: FIND→MATCH, INSERT→CREATE, UPDATE→SET, DELETE→DELETE, COUNT→COUNT.

## Deliverable 1: Neo4j Driver (`pkg/drivers/neo4j/`)

### OQL → Cypher Translation

| OQL Action | Cypher Template |
|---|---|
| `FIND` | `MATCH (n:Target) WHERE ... RETURN n` |
| `INSERT` | `CREATE (n:Target {props}) RETURN n` |
| `UPDATE` | `MATCH (n:Target) WHERE ... SET n.key = val RETURN n` |
| `DELETE` | `MATCH (n:Target) WHERE ... DELETE n` |
| `COUNT` | `MATCH (n:Target) WHERE ... RETURN count(n)` |
| `BATCH_INSERT` | `UNWIND $batch AS row CREATE (n:Target) SET n = row RETURN n` |

### OQL Filter → Cypher WHERE Translation

| OQL Operator | Cypher Expression |
|---|---|
| `{"name": "Alice"}` or `$eq` | `n.name = $p1` |
| `$ne` | `n.name <> $p1` |
| `$gt` / `$gte` | `n.age > $p1` / `n.age >= $p1` |
| `$lt` / `$lte` | `n.price < $p1` / `n.price <= $p1` |
| `$in` | `n.status IN $p1` |
| `$nin` | `NOT n.status IN $p1` |
| `$or` | `(condition1) OR (condition2)` |
| `$and` | `(condition1) AND (condition2)` |

Parameters use the `$pN` style (Neo4j native parameter syntax).

### Driver Implementation

package neo4j

import (
    "context"
    "fmt"

    "github.com/neo4j/neo4j-go-driver/v5/neo4j"
    "github.com/Uttam-Mahata/omniql/pkg/core"
)

// Driver implements core.Driver for Neo4j.
type Driver struct {
    driver  neo4j.DriverWithContext
    dbName  string // empty string = default database
}

// New creates a new Neo4j driver.
// uri format: "neo4j://localhost:7687" or "bolt://localhost:7687"
func New(uri, username, password, dbName string) (*Driver, error) {
    driver, err := neo4j.NewDriverWithContext(uri, neo4j.BasicAuth(username, password, ""))
    if err != nil {
        return nil, fmt.Errorf("neo4j connect: %w", err)
    }
    return &Driver{driver: driver, dbName: dbName}, nil
}

}

func (d *Driver) Ping(ctx context.Context) error {
    return d.driver.VerifyConnectivity(ctx)

### Cypher Builder (`pkg/drivers/neo4j/cypher.go`)

```go
// buildWhere converts an OQL filter to a Cypher WHERE clause.
// Returns the clause string, parameter map, and next parameter index.
func buildWhere(
    filter map[string]interface{},
    nodeVar string,  // e.g., "n"
    startIdx int,
) (clause string, params map[string]interface{}, nextIdx int, err error)
```

The Cypher WHERE builder is separate from `sqlutil.BuildWhere` because:
- Neo4j uses `$pN` parameters (not positional)
- Property access is `n.field` not quoted identifiers
- `IN` uses native list parameters (no need to expand)
- Logical operators use `OR`/`AND` keywords (same as SQL but different parameter handling)

### Options Support

| OQL Option | Cypher Mapping |
|---|---|
| `limit` | `LIMIT $limit` |
| `skip` | `SKIP $skip` |
| `sort: {"name": 1}` | `ORDER BY n.name ASC` |
| `sort: {"name": -1}` | `ORDER BY n.name DESC` |
| `fields: {"name": 1, "age": 1}` | `RETURN n.name, n.age` (instead of `RETURN n`) |

## Deliverable 2: Registration Points

### CLI (`cmd/omniql/main.go`)

Add `-driver neo4j` case:

```go
case "neo4j":
    drv, err := drvneo4j.New(dsn, user, pass, db)
    if err != nil {
        return fmt.Errorf("neo4j: %w", err)
    }
    engine.RegisterDriver(drv)
```

Neo4j requires authentication, so add `-user` and `-pass` flags to the CLI (or encode in DSN as `neo4j://user:pass@host:port`).

### Config (`cmd/omniql/config.go`)

Add `user` and `password` fields to `DriverConfig`:

```go
type DriverConfig struct {
    Type     string `yaml:"type"`
    DSN      string `yaml:"dsn"`
    DB       string `yaml:"db,omitempty"`
    User     string `yaml:"user,omitempty"`     // for neo4j
    Password string `yaml:"password,omitempty"` // for neo4j
    Token    string `yaml:"token,omitempty"`    // for influxdb
    Org      string `yaml:"org,omitempty"`      // for influxdb
    Bucket   string `yaml:"bucket,omitempty"`   // for influxdb
}
```

Example config:
```yaml
drivers:
  graph:
    type: neo4j
    dsn: "neo4j://localhost:7687"
    user: neo4j
    password: "${NEO4J_PASSWORD}"
    db: mydb

routes:
  people: graph
  knows:  graph
```

## Deliverable 3: Compliance Suite for Neo4j

Add Neo4j to the compliance suite. Neo4j integration tests run when `NEO4J_URI` is set.

### Factory Helper

```go
func neo4jDriver(t *testing.T) (core.Driver, func()) {
    t.Helper()
    uri := os.Getenv("NEO4J_URI")
    if uri == "" {
        t.Skip("NEO4J_URI not set; skipping Neo4j compliance tests")
    }
    user := os.Getenv("NEO4J_USER")
    pass := os.Getenv("NEO4J_PASSWORD")
    db := os.Getenv("NEO4J_DB")

    drv, err := drvneo4j.New(uri, user, pass, db)
    if err != nil {
        t.Fatalf("neo4j driver: %v", err)
    }

    // Clean up: delete all nodes with the test label
    cleanup := func() {
        // MATCH (n:products) DETACH DELETE n
        drv.Close()
    }
    return drv, cleanup
}
```

Note: The compliance suite uses a `products` table. For Neo4j, this becomes a `products` node label. The existing tests should work because OQL is database-agnostic — `target: "products"` maps to `MATCH (n:products)`.

## Deliverable 4: Graph-Specific OQL Extensions (Future-Facing)

Document (but do not implement in v1.0.2) potential graph-specific OQL extensions for future versions:

### Planned Extensions (v1.1+)

```json
{
  "target": "people",
  "action": "FIND",
  "filter": { "name": "Alice" },
  "options": {
    "traverse": {
      "relationship": "KNOWS",
      "direction": "outgoing",
      "depth": 2
    }
  }
}
```

This would generate: `MATCH (n:people {name: 'Alice'})-[:KNOWS*..2]->(m) RETURN m`

For v1.0.2, the driver only supports basic CRUD. Graph traversal is documented as a future enhancement.
